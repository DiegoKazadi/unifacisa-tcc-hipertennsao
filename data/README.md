# Dados

`raw/` contém cópias dos arquivos recebidos. Não editar nem sobrescrever esses originais.

- `raw/cleveland/`: arquivos identificados como Cleveland Heart Disease.
- `raw/framingham/`: arquivos identificados como Framingham.
- `raw/other/`: reservado para outros arquivos.
- `processed/`: somente dados derivados, com transformações documentadas.

Antes de modelar, confirmar o significado do alvo e a licença/origem de cada arquivo.
