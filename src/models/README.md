# Modelos

Os scripts específicos dos quatro algoritmos serão implementados depois de confirmar:
1. a base de dados efetivamente usada no TCC;
2. a variável-alvo;
3. as opções dos algoritmos e o procedimento de validação no WEKA.

Para reprodução fiel, a primeira escolha é recuperar as configurações do WEKA. Uma implementação Python moderna pode ser adicionada como comparação, mas não deve ser chamada de reprodução exata sem validar diferenças entre algoritmos e parâmetros.

Arquivos planejados:
- `bayesian_network.py`
- `logitboost.py`
- `mlp.py`
- `j48.py`
