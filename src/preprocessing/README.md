# Pré-processamento

`prepare_data.py` inspeciona um CSV e salva uma cópia de trabalho depois de o usuário informar explicitamente a coluna-alvo confirmada.

Não altera os arquivos em `data/raw/`. Não execute com uma variável-alvo presumida: alguns arquivos fornecidos são de doença cardíaca, e isso pode não corresponder ao objetivo do TCC.
